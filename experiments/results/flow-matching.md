# Flow Matching 条件速度与边缘速度实验

2026-11-12 实测。[精读](../../notes/flow-matching.md) · [脚本](../flow_matching.py) · [原始 JSON](flow-matching.json)

## 假设和边界

用独立高斯端点验证条件平方损失、边缘场和时间方向。参照为本项目推导的解析公式，机制对应原文 §3 Theorem 2 与 §4.1；不是图像生成复现。网络训练预算为零，闭式最小二乘用于有限样本统计校验，无泛化指标。

## 可复现配置

Python 3.9.6，macOS 27.2.1 arm64，CPU 标准库，无外部数据或联网下载。脚本 SHA-256：`ed413215490a8d2e6b95126eb3818acb58b3c10c42c410df638d32b3e27c8d58`。

```bash
python3 experiments/flow_matching.py --output /tmp/flow-matching.json
python3 -m unittest discover -s experiments -p 'test_flow_matching.py' -v
```

独立端点 $z\sim N(0,1)$、$y\sim N(2,0.25)$，种子 7、42、2026 各生成 30,000 对；各时刻共用该种子的端点，时刻为 0.25、0.5、0.75。均值/协方差的闭式公式作为参照，不使用测试集评估训练后的模型。确定性 ODE 输入为 (-2,-1,0,1,2)，Euler 步数 400、800，终点参照为 $2+0.5z$。

条件路径导数单独使用正终点噪声 0.1、固定端点 (-1.5,3)。其他高斯检查取终点噪声 0 的教学极限；它的边缘方差始终为正。有限差分步长 1e-5，检查时刻为 0.2、0.5、0.8。

## 对照与指标

- 条件路径导数误差 <1e-9；边缘解析流导数误差 <1e-8。
- 线性预测器 (a,b) 为 (0,0)、(1,0)、(-1,2)、(3,-2)。每个时刻直接计算两个总体平方损失，差值与条件方差的误差 <1e-12。
- 三个种子、三个时刻的斜率/截距最大绝对误差均 <0.06。阈值在运行前写入脚本；保留全部种子。
- 800 步的最大终点绝对误差 <0.01，且小于 400 步误差的 0.6 倍。
- 反转时钟并同时反转速度时，与原时钟解相差 <1e-10；故意漏掉速度负号后，零初值的终点与正确终点 2 相差 >1。

## 解释与局限

有限采样产生回归误差；高斯闭式参照隔离了目标定义，Euler 的收敛检查隔离了数值积分。没有训练时间条件网络，不能比较 FM 与 DDPM 的训练成本、FID 或图像采样速度。此处独立配对产生的路径也不是全局最优运输路径。任何检查失败时脚本返回非零状态，不能仅保留最佳种子。
