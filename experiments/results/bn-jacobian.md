# BatchNorm 统计量求导与冻结对照（2026-11-20）

## 假设和边界

验证 [BN 精读](../../topics/02-training/notes/batch-normalization.md) 中自行推导的单特征 Jacobian，与原文 §3 链式法则对应。冻结统计量与训练态在基点可有相同输出，但导数不同。只验证算子，不是训练加速或论文基准复现。

## 可复现配置

- 脚本：[bn_jacobian.py](../bn_jacobian.py)，SHA-256 `1d1cbcb5930a2796ca6165724c1eb2abc1d38b919dcf2467b48acc3bc4e1b86a`。
- 实测环境：Python 3.9.6，macOS 27.2.1 arm64；标准库、CPU，无下载或外部数据。CI 另测 Python 3.10/3.12。
- 输入 [-3,−1,2,6]，γ=1.5、β=0.3；ε=0 与 0.25；公共平移 +5；中心差分步长 1e-5。
- seed=null：确定性计算，无训练、测试集划分或随机筛选。原始结果：[JSON](bn-jacobian.json)。

```bash
python3 experiments/bn_jacobian.py --output /tmp/bn-jacobian.json
python3 -m unittest discover -s experiments -p 'test_bn_jacobian.py' -v
```

## 对照与指标

解析 Jacobian 对照逐坐标中心差分，最大绝对误差须 <1e-8；训练态公共平移输出变化及 J1 须 <1e-12；非对角元素最大值须 >0.01。ε=0 的 Jc 须 <1e-12；ε=0.25 的 Jc 与 γεc/s³ 误差须 <1e-12 且最大幅值 >0.01，避免把近似零误当一般结论。

冻结 μ₀=1、v₀=11.5 后，差分须匹配 γI/s，误差 <1e-8；公共平移的输出差须匹配 5γ/s，误差 <1e-12，且 γ/s>0.1。冻结分支是独立的函数对照，不宣称它就是训练态的正确梯度。任一检查失败脚本非零退出。

## 实际结果

| ε | 解析/差分最大误差 | max abs(Jc) | 冻结统计量的公共平移增益 γ/s |
|---|---|---|---|
| 0 | 3.1815e-11 | 1.1102e-16 | 0.4423258685 |
| 0.25 | 4.6559e-11 | 0.0465526569 | 0.4375949745 |

两组训练态平移输出差均为 0；非对角项最大幅值分别为 0.1875077051、0.1838829946。6 项检查全部通过。

6 项独立语义测试覆盖两元素手算、恒定批次横向导数、单元素代数退化、不同批与负/零 γ 的差分、公共偏置负对照、非法输入与零分母。两元素 [-1,1]、ε=3、γ=1 的手算 Jacobian 为 `[[0.1875,-0.1875],[-0.1875,0.1875]]`；冻结对照为 `0.5 I`。这类独立参照可识别漏掉统计量梯度的实现。

## 解释与局限

共同平移方向被训练态中心化消除；非零 ε 留下径向导数。局部零方向既不是全部梯度消失，也不能单独解释训练收益。本实验没有测量滑动统计估计、数据分布偏移、卷积空间相关性或神经网络收敛。原 normalization 前向实验及已存基线保持不变。
