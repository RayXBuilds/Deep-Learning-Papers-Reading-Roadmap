# Dropout 的推理缩放与 VGG 的小核堆叠

2026-11-21 在 macOS arm64 CPU 使用 Python 3.9.6 标准库计算。两个实验均为确定性穷举，种子不适用，无数据下载、训练集或拟合步骤。在仓库根目录运行下列命令，第一条打印指标及脚本 SHA-256，任一通过条件失败会返回非零状态。

```sh
python3 experiments/early_mechanisms.py
python3 -m unittest discover -s experiments -p 'test_early_mechanisms.py'
```

**Dropout**　固定两个输入的加权贡献为 2 和 −4，偏置 1，独立保留概率 1/2。四个等概率子网的预激活为 1、−3、3、−1。通过条件为仿射均值等于缩放基线 0，ReLU 后均值等于 1，而缩放后 ReLU 为 0。把偏置移到 5 则所有响应同号，线性与 ReLU 均值都应为 4。实测均满足。另用非对称保留概率及全留、全丢测试检验掩码权重。这个固定权重的推理实验没有衡量泛化。

**VGG**　从无限二维网格的单点脉冲出发，取一个输入和一个输出通道，步幅 1，无偏置、非线性和池化。基线是一次全一 7×7 卷积，对照为三次全一 3×3 卷积。通过条件为支持集合的 49 个坐标完全相同，但中心系数分别为 1、49，堆叠核角点系数为 1；总和分别为 49 和 729。实测均满足。独立测试用一维多项式系数的外积检查整个二维响应。这里观测的是空间支持和路径条数，无法推断真实网络学到的权重、延迟或分类误差。
