# Flow Matching 双峰表达能力补充

2026-11-13 实测。[精读与推导](../../notes/flow-matching.md) · [脚本](../flow_mixture.py) · [JSON](flow-mixture.json)

## 假设和边界

验证位置相关的后验分量权重使双峰边缘速度非线性；比较有限样本线性回归与解析条件均值，并隔离积分误差。它是原文 Eq. (8) 的原创教学算例，属于已有 Flow Matching 专题，不计为新论文或完整复现。

## 可复现配置

CPU 标准库，无外部数据。等权目标 N(-2,0.25) 与 N(2,0.25)，噪声 N(0,1)，独立端点线性插值，终点噪声取 0 的教学极限。训练种子 7、42、2026，测试种子分别加 100000，各 10,000 对；每组内三个时刻共用端点。时刻为 0.25、0.5、0.75，训练预算为各时刻一次闭式最小二乘，无神经网络优化。

采样使用 200 个标准高斯中点分位数，解析场用 200/400 步 Euler，总体最优线性场用 400 步。采样未使用有限样本拟合的系数，防止把拟合噪声混入表达能力对照。NFE 等于步数。

```bash
python3 experiments/flow_mixture.py --output /tmp/flow-mixture.json
python3 -m unittest discover -s experiments -p test_flow_mixture.py -v
```

环境：Python 3.9.6，macOS-27.2.1-arm64-arm-64bit。脚本 SHA-256：`ba50560d71c1902843c12c2fa1ce6dab06b50fec23a00abf3f1458f3ddb53a3a`。

## 对照与指标

运行前固定的通过条件：三个种子在 t=0.5 的线性测试 MSE 均比解析参照大 0.1 以上，预测场对解析场的 MSE 也均大于 0.1；解析场 400 步 CDF 误差小于 0.02 且低于 200 步；线性场 400 步误差大于 0.1；解析场左右峰区间质量各自与目标相差小于 0.02。

CDF 误差定义为各采样分位点上 max |F_target(x_i)-q_i|，不是全实轴 KS 上确界。峰区间分别为 (-3,-1)、(1,3)，比较概率质量，不把仅左右符号各半称为成功覆盖。解析参照使用已知目标分布，不能与学习算法作公平性能排名。

## 实际结果

| 种子 | t=0.5 线性测试 MSE | 解析参照测试 MSE | 预测场 MSE |
|---|---|---|---|
| 7 | 3.261057 | 1.927505 | 1.342555 |
| 42 | 3.287096 | 1.963712 | 1.308090 |
| 2026 | 3.193088 | 1.883645 | 1.300697 |

| 场 / 步数 | 分位点最大 CDF 误差 | 左峰质量 | 右峰质量 |
|---|---|---|---|
| 解析 / 200 | 0.00234891 | 0.48 | 0.48 |
| 解析 / 400 | 0.00117433 | 0.48 | 0.48 |
| 总体线性 / 400 | 0.19628644 | 0.245 | 0.245 |

目标每个峰区间质量为 0.47724987。5 项机制检查、5 项新增语义测试通过；JSON 保存全部时刻、种子、采样终点和环境。

## 解释与局限

t=0.5 的线性表达偏差在三个种子下持续存在；解析积分加倍步数后误差约减半。总体线性场即使没有参数估计误差，也不能正确生成两个峰。结果仅支持这个一维例子；没有测试神经网络、多维模式、非等权混合或真实图像。峰区间统计分辨率为 1/200；代码任一机制检查失败即返回非零状态。
