## 对照与指标

| 检查 | 独立参照与通过条件 |
|---|---|
| 首步 L2 | 偏差校正后 m_hat=g、v_hat=g² 的手算值；最大参数误差 < 1e-12 |
| 首步 AdamW | 两坐标都乘 0.99；最大误差 < 1e-12；与 L2 最大参数差 > 0.08 |
| 矩状态 | 相同外部梯度流下，AdamW 有/无衰减的 m、v 差 < 1e-12 |
| 调度累计衰减 | 零梯度、零初始矩时乘积 0.99*0.995*0.999；误差 < 1e-12 |
| SGD 参照 | 无动量 SGD 的 L2 与匹配衰减式误差 < 1e-12 |
| 轨迹 | 全部 201 个状态有限，三组使用相同目标和更新预算；不设“谁损失最小谁通过” |

单元测试另覆盖：旧参数衰减顺序的负对照、已有动量时零当前梯度仍会移动、零衰减时两种模式逐步一致、二次梯度中心差分（h=1e-6，比较到 7 位小数）、输入不被修改及非法参数拒绝。失败时保留输出并返回退出码 1。

## 实际结果

[完整 JSON](adamw-decay.json)保存所有状态与配置。七项实验验收通过；新增八项语义测试通过，全库合计 41 项通过。

首步 Adam+L2 得 **(0.900000010, 9.900000001)**，AdamW 得 **(0.99, 9.9)**。后者首步 m=v=0；前者正则项已进入 m、v。外部梯度对照的矩差为 **0**；调度后的参数为 **(1.9681299, -2.95219485)**，与累计乘积参照一致。

固定目标初值均为 2.5，200 次更新后：

| 方法 | x | y | 未加正则的 f(x,y) |
|---|---:|---:|---:|
| adam | 2.000028451 | -1.000028451 | 2.0236960116e-09 |
| adam_l2 | 1.818152529 | -0.975629544 | 0.017722089614 |
| adamw | 1.965036055 | -0.982832902 | 0.00120065725297 |

不加正则的最优点是 (2,-1)；加上 0.1*(x²+y²)/2 的解析最优点是 (2/1.1,-4/4.1)，Adam+L2 的终点接近它。目标已经改变，因此不能仅用未加正则的损失判定该方法失败。AdamW 此处也不应被解释成在优化同一个固定欧氏 L2 目标。

## 解释与局限

实验验证更新差异及实现约定，没有验证论文中的图像泛化收益。无随机数，重复三个种子不会提供新的证据；真实数据训练仍应固定划分、调参预算并运行多个种子。

衰减从矩估计中解耦，不代表它与学习率和更新次数无关。当前协议使用常见 API 的系数约定，没有 normalized weight decay、参数分组或学习率搜索。原有核心五项脚本和基线哈希未修改。
