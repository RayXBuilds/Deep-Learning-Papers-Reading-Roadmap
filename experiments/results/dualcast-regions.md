# DualCast 区域损失机制实验

2026-11-11 实测。[精读](../../notes/dualcast.md) · [脚本](../dualcast_regions.py) · [JSON](dualcast-regions.json)

## 假设和边界

验证原文 Eq. (9)、(11) 的区域权重、通道归一化及 §3.3 的丢弃后掩码重算。输入已完成对齐和二值化，网络训练预算为零。

## 可复现配置

Python 3.9.6，macOS 27.2 arm64，CPU 标准库。seed=null，无随机数或外部数据。商品掩码 (0,1,0,1)，脸部掩码 (0,0,1,1)，残差通道分别为 (1,2,3,4) 和 (4,3,2,1)，时间权重固定为 1，数值稳定项为 1e-8。

脚本 SHA-256 为 `5307fde74a9618408288b3312356dcc71cc6f7ab352d66c154fcaa2ec3ebc8b7`。

```bash
python3 experiments/dualcast_regions.py --output /tmp/dualcast-regions.json
python3 -m unittest discover -s experiments -p 'test_dualcast_regions.py' -v
```

## 对照与指标

权重表和丢弃后的表要求逐项精确匹配。手算损失参照为 111.5/(15+1e-8)，误差阈值 1e-12。全体残差设为 2 时损失与 4 相差小于 1e-8。公共权重翻倍前后损失相差小于 1e-8，容差考虑固定稳定项。语义测试另覆盖单位置双通道、零权重和非法输入。

## 解释与局限

验证范围是局部损失计算。真实分割掩码、时间采样、潜空间压缩、生成槽位、训练收敛和视频质量仍待验证。权重归一化的误差阈值只针对本配置，极小总权重下的稳定项影响需要单独分析。
