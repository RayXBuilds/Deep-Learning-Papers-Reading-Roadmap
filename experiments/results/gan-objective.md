# GAN 概率表与梯度实测

记录日期为 2026-11-05，运行范围为 CPU 机制验证。[精读](../../notes/gan.md) · [脚本](../gan_objective.py) · [JSON](gan-objective.json)

## 假设和边界

检查最优判别器代回 minimax 目标后的 JS 等式，以及两种生成器损失对 logit 的导数。神经网络训练和图像基准尚未执行。

## 可复现配置

Python 3.9.6，macOS-27.0.1-arm64-arm-64bit，仅标准库。输入为两状态概率表，匹配例为 p=q=[0.75,0.25]，错配例为 p=[0.75,0.25]、q=[0.25,0.75]，分离例为 p=[1,0]、q=[0,1]。输入确定，seed=null，使用精确求和，无采样或数据划分。标量 logit 为 -8、0、8，中心差分步长为 1e-5。

```bash
python3 experiments/gan_objective.py --output /tmp/gan-objective.json
python3 -m unittest discover -s experiments -p 'test_gan_objective.py' -v
```

脚本 SHA-256 为 `9ece58a97ed8db55d477a668fc7407b24b52d8189b66e88d5921daf2501c91d5`。

## 对照与指标

等式误差须小于 1e-12，导数绝对误差须小于 1e-8。错配例的最优判别器值须超过恒定 1/2 判别器的值至少 0.1。s=-8 时 minimax 导数绝对值须小于 0.001，非饱和导数绝对值须大于 0.999。检查失败时脚本退出码为 1。

## 实际结果

| 配置 | C | JS |
|---|---:|---:|
| 匹配 | -1.386294361120 | 0 |
| 错配 | -1.124670289238 | 0.130812035941 |
| 支持集分离 | 0 | 0.693147180560 |

恒定判别器给出 -log 4，错配例的 D* 为 [0.75,0.25]，目标改善约 0.261624。s=-8 时 minimax 与非饱和解析导数分别为 -0.000335350130 和 -0.999664649870，有限差分与解析值满足容差。6 项机制检查全部通过，语义测试另覆盖手算最优值、零质量状态、JS 对称性、极端 logit 和非法概率输入。

## 解释与局限

恒定输出的损失值可以与匹配情形相同，因此还需要判别器优化程度的信息。支持集分离例检验概率公式的端点行为。logit 导数仍需乘上网络 Jacobian 才得到参数梯度，真实训练稳定性和收敛尚待验证。
