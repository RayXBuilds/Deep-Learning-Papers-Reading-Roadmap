# Robust Flow Matching 残差与比较评分机制

2026-11-14 实测。[精读](../../notes/robust-flow-matching.md) · [脚本](../robust_flow.py) · [JSON](robust-flow.json)

## 假设和边界

验证原文 Eq. (7)、(10)、(16)–(17) 的局部代数与评分顺序。固定场，不运行 TRS/CCS 训练或神经网络，不测 FID。

## 可复现配置

CPU 标准库，无外部数据，seed=null。输入 x0=0、x1=1、端点偏移=1，场 v=2x；时间为 0、0.25、0.5、0.75、1。标签干预把截距从 0 改为 3。CCS 两行三列损失表为 (2,1,9)、(2,9,1)，观测列 0，温度 1。时间积分用 10000 个均匀中点的平方根，无训练/测试划分，因为没有估计参数或泛化评价。

```bash
python3 experiments/robust_flow.py --output /tmp/robust-flow.json
python3 -m unittest discover -s experiments -p test_robust_flow.py -v
```

环境：Python 3.9.6，macOS-27.2.1-arm64-arm-64bit。脚本 SHA-256：`b2476e284d630995a6d46267d15d735350ae68eaef2cfdf7a6e272cdbc7a0098`。

## 对照与指标

残差差值与 (2t-1) 的误差必须小于 1e-12；中点路径偏移非零而残差差值为零。标签干预差值严格等于 3。正确 CCS 必须为 1，错误运算顺序为 -3。负分/零分/正分权重严格递减，零分为 1/2。晚偏时间均值与 2/3 误差小于 1e-6。阈值运行前固定在代码中。

## 实际结果

残差差值为 (-1,-0.5,0,0.5,1)，对应路径偏移 (0,0.25,0.5,0.75,1)。CCS=1，错误顺序=-3；分数 -1、0、1 的权重分别为 0.73105858、0.5、0.26894142。晚偏时间均值为 0.6666667273。

6 项机制检查与 5 项新增语义测试通过，JSON 保存全部输入与输出。语义测试包括排除观测标签、数值极端、手算残差和非法输入。

## 解释与局限

路径偏移变大不强制残差单调增大；CCS 要逐时刻选竞争条件。固定表不证明真实训练能识别坏样本。本实验未实现 EMA 缓冲区、分位数、刷新调度或鲁棒训练，官方 2D/CIFAR 基准仍待复现。失败时脚本返回非零状态。
