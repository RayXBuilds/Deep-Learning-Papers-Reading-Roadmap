# EBGAN PT 的维数下界补充实验

记录日期为 2026-11-08。[精读](../../notes/ebgan.md) · [脚本](../ebgan_dimension.py) · [JSON](ebgan-dimension.json)

## 假设和边界

检验 N 个 d 维非零表示的 PT 下界 max(0,(N-d)/(d(N-1)))，以及达到下界时仍存在重复表示的构造。推导见精读，是对原论文 Eq. (14) 的教学分析。属于既有 EBGAN 专题的补充实验，未训练网络。

## 可复现配置

CPU、Python 3.9.6、macOS 27.2 arm64，标准库，无外部数据。seed=null，输入确定，训练预算为零。输入保存在 JSON，依次为两个二维正交单位向量、三个夹角 120° 的单位向量、两条正交轴各重复两次、四个共线向量 (1,0)、(2,0)、(-1,0)、(-2,0)。无随机采样或数据划分。

```bash
python3 experiments/ebgan_dimension.py --output /tmp/ebgan-dimension.json
python3 -m unittest discover -s experiments -p 'test_ebgan_dimension.py' -v
```

## 对照与指标

成对求和复用既有 PT 函数，独立参照通过 UᵀU 的元素平方和计算。两种公式误差、理论下界与达到下界的构造误差阈值为 1e-12。四共线向量作为高损失负对照。新增语义测试另用三维坐标轴各重复两次，手算 PT=3/15=0.2，验证更换维数后的重复构造。任一检查失败均返回非零退出码。

## 实际结果

| 输入 | PT | 理论下界 |
|---|---:|---:|
| 两正交向量，N=2、d=2 | 0 | 0 |
| 三等角向量，N=3、d=2 | 0.24999999999999997 | 0.25 |
| 重复坐标轴，N=4、d=2 | 0.3333333333333333 | 0.3333333333333333 |
| 四共线向量，N=4、d=2 | 1 | 0.3333333333333333 |

独立矩阵参照与成对求和一致，5 项机制检查通过，2 项新增测试通过。旧版 EBGAN 的脚本和记录可从原实验入口查阅。[原实验](ebgan-energy.md)

## 解释与局限

维数约束给出非零下界，重复表示也可达到下界。实际生成质量、训练稳定性、真实数据覆盖及加入 epsilon 后的行为尚未验证。
