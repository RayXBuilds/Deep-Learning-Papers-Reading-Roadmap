# BERT MLM 的监督位置与权重 · 2026-11-03

[精读](../../notes/bert.md) · [原始 JSON](bert-mlm.json) · [脚本](../bert_mlm.py)

## 假设和边界

验证固定 logits 下的加权词表交叉熵：选中但未替换、选中且随机替换的位置都参与损失；零权重槽不参与分子或分母。对应原论文 §3.1 与官方 `get_masked_lm_output`。不实现编码器、候选采样、80/10/10 输入扰动、预测头、NSP 或训练。

## 可复现配置

Python 3.9.6，macOS-27.0.1-arm64-arm-64bit，CPU 标准库；项目推荐 Python 3.10+。固定四个预测槽、三词词表，标签 `[0,1,2,0]`，权重 `[1,1,1,0]`。前三行 logits 分别为 `[ln(3),0,0]`、`[0,ln(2),0]`、`[0,0,ln(4)]`，末行 `[5,-2,1]`。前三槽分别模拟遮盖、选中未替换、随机替换；这里只提供标签与 logits，不生成这些输入情形。无随机数，种子不适用；无数据集、划分、下载或训练预算。

## 对照与指标

保持 logits 固定，分别改变未选槽、未替换预测槽、随机替换预测槽的标签；另改变零权重槽的 logits 或直接移除该槽。手算参照为 `(ln(5/3)+ln(2)+ln(1.5))/(3+1e-5)`。分母小常数与核对的官方实现一致；零权重槽仍要求合法词表标签，本接口不使用 -100 忽略标记。

预定验收：手算误差与无关干预差异 <1e-12；两种选中位置的标签干预均增加损失 >0.1；只计算遮盖槽的错误实现与正确损失相差 >0.01；全部权重为零时返回零。非零差异是本构造的反例条件，不是所有 logits 的保证。

7 项机制检查、6 项语义测试通过。测试另含均匀分布手算、分数权重、logit 平移不变性、极端 logits 的稳定性和非法输入拒绝。记录所有对照，不挑选最佳结果。

## 解释与局限

这验证的是损失计算，不验证 MLM 数据构造或学习效果。固定 logits 下未选槽无直接损失，不意味着它作为上下文时没有上游梯度。全零权重返回零只是数值行为，训练管线仍应监测没有有效监督的批次。本实验没有 BERT 权重推理或语言理解指标。
