# TRS 样本评分缓冲区实验

2026-11-15 实测。[精读及固定版本来源](../../topics/05-generative/notes/robust-flow-matching.md) · [脚本](../trs_buffer.py) · [JSON](trs-buffer.json)

## 假设和边界

检查样本身份、首次观察、稀疏更新、已访问分位数与暖启动单位权重。基于论文 §4.1 Eq. (14) 及作者二维实现的局部行为，参数为教学选择；未运行模型、优化器或官方训练。

## 可复现配置

CPU 标准库，无外部数据，seed=null。四个样本，初始分数为 None；两批唯一 ID 到损失的映射分别为 {0:1,1:3}、{0:5,2:9}。beta=0.5、分位点=0.5、温度=1；首次访问直接记录。排序位置 (n-1)p 采用线性插值。无训练/测试划分，因为输入为固定状态机用例，不报告泛化。

```bash
python3 experiments/trs_buffer.py --output /tmp/trs-buffer.json
python3 -m unittest discover -s experiments -p test_trs_buffer.py -v
```

环境：Python 3.9.6，macOS-27.2.1-arm64-arm-64bit。脚本 SHA-256：`6d81e6f89e45761f1b5421b7eadcda75b691174ee275789159ac32ea62743469`。

## 对照与指标

预设通过条件：首次缓冲区严格等于 (1,3,None,None)，第二次等于 (3,3,9,None)；第一批已访问中位数为 2，错误零填充中位数为 0.5；暖启动全为 1；第二批阈值为 3，低分并列权重为 0.5，高分权重小于 0.01；未访问接口权重为 1。

## 实际结果

6 项机制检查、6 项新增语义测试通过。第二批权重 (0.5,0.5,0.0024726231566347748,1)，第一批/第二批分数与上述手算一致。JSON 保留配置及所有中间状态。测试另验证 0.7 分位数插值、输入不被修改、首次观察不受零初始化偏差、无已访问项及非法输入。

## 解释与局限

这验证了评分状态管理，没有证明高残差样本真的损坏。未访问权重为 1 是接口约定，不是可信度判定；当前批需先更新再加权。本教学实现不接受同批重复 ID，未复现 PyTorch 索引写入行为。官方二维代码的 beta=0.99、分位点=0.7，与教学参数不同；原文暖启动描述与该版本 score-only 阶段也有区别，见精读。缓冲区评分不等于端到端 TRS 训练。
