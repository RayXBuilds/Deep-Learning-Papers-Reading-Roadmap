# ViT 图像块与位置排列 · 2026-11-02

[精读](../../notes/vit.md) · [实验导航](../README.md) · [原始 JSON](vit-patches.json)

## 假设和边界

针对 ViT 原文 §3.1 的输入路径，验证共享块投影与步长卷积等价，以及无位置的注意力对 token 排列等变。反例区分错误通道约定、固定位置只换内容、内容连位置一起换。只验证算子机制，不训练 ViT，不评价分类或学习到的空间关系。

## 可复现配置

- [脚本](../vit_patches.py) SHA-256：`16b7db40264c59ff32f70dccd30d05e26949c36e9ce16b20c1a921dd8c8d4d24`。
- 实际运行：Python 3.9.6，`macOS-27.0.1-arm64-arm-64bit`，CPU 标准库；项目推荐 Python 3.10+。
- 图像 HWC=4×4×2，元素 `X[y][x][c]=(8*y+2*x+c+1)/32`，P=2；块内顺序行→列→通道，块按行优先排列。
- 权重 8×2，第 t 行为 `[(t+1)/10, (-1)**t*0.2]`，不加偏置；卷积参考核按同一映射重排，独立循环按通道→列→行累加。
- 四个投影 token 前加 CLS `[0.2,-0.1]`；位置表 `[[0,0],[0.1,0.2],[-0.3,0.1],[0.4,-0.2],[-0.1,-0.4]]`；置换 `[0,3,1,4,2]` 固定 CLS 位置。
- 单头缩放点积注意力，Q/K/V 为恒等映射，无掩码、dropout、LN、MLP 或训练。无随机数，seed=null；无数据集、划分、外部下载。

```bash

```

## 对照与指标

运行前固定：投影/卷积、无位置等变/CLS 不变、联合重排等变/CLS 不变误差均 <1e-12；错误展平的输出差异 >0.01；固定位置只换内容的 CLS 差异 >1e-4。后两者只要求此构造反例有效，不声称每个输入或位置表都产生非零差异。

独立语义测试核对双通道手工块顺序、可手算的投影/卷积输出 `[4321,4]`、两 token softmax、另一维度/置换、P=1 与整图分块，以及非法输入。脚本拒绝不能整除的图像尺寸，避免隐式裁剪；未声称与官方卷积在所有非法尺寸上的处理相同。

|---|---:|

| 无位置，CLS 不变误差 | 0 |
| 固定位置，只换内容的 CLS 变化 | 0.0279617561 |

| 内容/位置联合重排，CLS 不变误差 | 6.6613e-16 |

7 项机制检查与 7 项语义测试全部通过；完整输入、投影和各条件输出见 JSON。没有随机抽样或重复选最佳值。浮点误差来自累加顺序，不表示模型学到了近似不变性。

224×224 输入含 CLS 时，P=16/32 的 token 数分别为 197/50，单头分数矩阵元素数比例为 15.5236；此项仅为算术说明，未计时或测显存。

## 解释与局限

图像块投影与卷积的等价依赖相同参数、通道布局、步长和填充。位置标签能够打破“只重排内容”的对称性，但一起搬动内容与标签只是对带标签集合重排。没有验证完整编码器、学习的位置表、位置插值、分类头或数据规模效应；不能从本实验推断 ViT 优于 CNN。
