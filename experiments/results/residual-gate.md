# ResNet 加法后激活与抵消实验

2026-11-19。[精读](../../notes/resnet.md) · [脚本](../residual_gate.py) · [JSON](residual-gate.json)

## 假设和边界

检验标量 y=ReLU(x+ax+b) 的链式导数。以恒等分支为参照，分别构造激活截断、分支抵消、梯度放大和收缩。没有卷积、BN 或训练，不复现分类精度。

## 可复现配置

Python 3.9.6，macOS-27.2.1-arm64-arm-64bit，CPU 标准库。x=1，(a,b,深度) 为 (0,0,20)、(-2,0,1)、(-1,0.5,1)、(1,0,20)、(-0.5,0,20)。无随机性，seed=null；无数据下载或训练/测试划分。中心差分步长 1e-6。

```bash
python3 experiments/residual_gate.py --output /tmp/residual-gate.json
python3 -m unittest discover -s experiments -p test_residual_gate.py -v
```

## 对照与指标

预设：五种解析导数依次为 1、0、0、2²⁰、2⁻²⁰；关闭激活的截断对照导数为 -1；抵消用例输出为正的 0.5。每个差分误差除以 max(1,|解析导数|) 后小于 1e-8。主实验避开折点。

## 实际结果

6 项检查通过。五种导数分别为 1、0、0、1048576、9.5367431640625e-7；最大归一化差分误差为 2.676e-11。各项输出与差分保存在 JSON。

5 项语义测试通过，包括两步仿射手算、激活开关、不同输入的常数抵消、零深度与非法深度，以及折点约定。折点测试明确展示代码梯度 0 与中心差分 0.5 的区别；不能用中心差分在不可导点“证明”反传错误。

## 解释与局限

固定恒等捷径不等于梯度存在正下界，也不保证深层累乘稳定。这里的反例只否定无条件保证，不估计真实训练中发生概率。原始 residual 实验和基线哈希保持不变；图像数据上的普通/残差训练对照仍待完成。
