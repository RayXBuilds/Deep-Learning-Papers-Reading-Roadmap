# 起步与核心路线

[首页](../../README.md) · [论文索引](../papers.md)

学习顺序不等于发表顺序。不要求先通读整本教材，也不要求把所有历史论文全部读完。

## 每篇论文的三遍阅读

1. 定位问题：看摘要、引言和主要图表，写出任务、输入输出、对比对象。
2. 还原方法：追踪一条输入经过模型的路径，标出张量形状、损失和训练/推理差异。
3. 检查证据：核对数据划分、基线、消融和指标，再运行机制实验。把未验证的推测留在问题清单。

采用 [精读模板](../../templates/paper-note.md)，用自己的话解释，避免只翻译摘要。

## 核心学习单元

时间由基础决定；下表是先修关系，不是强制周计划。

| 顺序 | 内容 | 验收 |
|---|---|---|
| 0 | 链式法则、均值方差、矩阵乘法、softmax | 手算两层函数导数与三元素 softmax |
| 1 | [ResNet](../../notes/resnet.md) | 区分训练退化与过拟合，比较普通/残差路径 |
| 2 | [BN](../../notes/batch-normalization.md) → [LN](../../notes/layer-normalization.md) | 在 3×3 矩阵上标出各自统计轴 |
| 3 | [Adam](../../notes/adam.md) | 手算第一步偏差校正，比较至少两个学习率 |
| 4 | Encoder–Decoder → Attention → [Transformer](../../notes/transformer.md) | 改变未来 token，确认掩码使早期输出不变 |
| 5（生成方向选读） | [VAE](../../notes/vae.md) / GAN 概念 → [DDPM](../../notes/ddpm.md) | 区分已知前向噪声、预测噪声与逆向采样 |

## 怎样判断读懂了

能回答：原方法卡在哪里？新方法改变哪一步？哪项实验支持它？在什么条件下可能不成立？自己运行的实验到底验证了哪一句话？

原论文数字与本地实验必须分开。公式单元测试不代表复现成功；下降的训练损失不代表泛化有效。
