## 问题

输入商品图、人物图和文本，输出同时保持两种参考身份的视频。论文把商品和人物分配到固定角色位置，并用区域权重加强局部监督。[§3](https://arxiv.org/html/2611.05825v1)

## 方法与关键推导

参考图分别经 VAE 编码后置于视频潜序列首尾，中间位置参与生成。CLIP 特征提供交叉注意力上下文。区域权重按背景、商品、脸部、重叠区域取 0.5、2、2、3。丢弃某种条件时，相应掩码也须禁用并重算权重。[Eq. (4)–(11)、§3.3](https://arxiv.org/html/2611.05825v1)

```text
xτ = (1-τ)x0 + τε                 uτ = ε-x0
扩展潜序列 = [zp, xτ, zh]
L = ω(τ) Σ_c,i W_i (v_c,i-u_c,i)² / (C Σ_i W_i + ε_num)
```

下面是本项目对公式的实现分析。令 i 合并生成位置的时空索引，C 为通道数。每个位置的权重在所有通道共享，因此分母需要乘 C。实现时先截取生成位置，再计算加权误差，能让索引范围与公式一致。

把四个位置依次设为背景、仅商品、仅脸部、重叠，两个通道的残差分别取 (1,2,3,4) 与 (4,3,2,1)。分子为

```text
0.5×(1²+4²) + 2×(2²+3²) + 2×(3²+2²) + 3×(4²+1²)
= 111.5
C Σ_i W_i = 2×7.5 = 15
```

省略通道因子会把该例损失放大约两倍。把商品和脸部权重直接相加则会将重叠位置设成 4，改变作者指定的区域规则。

丢弃人物条件后，原来仅脸部的位置成为背景，原重叠位置成为仅商品，权重从 (0.5,2,2,3) 变为 (0.5,2,0.5,2)。条件图像与监督掩码需要同步处理。

固定权重时，对一个预测值的梯度为 `2ω W_i(v_c,i-u_c,i)/(CΣW+ε_num)`。提高某区域权重同时改变公共分母，因此其他区域的相对贡献也会变化。若所有残差均为 2，损失应接近 4，区域面积本身不会令它倍增。把全部权重乘相同正常数时，分子和分母主项同步缩放，有限的 ε_num 使等价关系带有微小误差。这些推论可用下方脚本逐项核对。

## 可验证实验

CPU、标准库、人工二值掩码、两个残差通道，seed=null，ω=1、ε_num=1e-8。独立手算分子与通道分母作为参照，检查重叠、条件丢弃、常量残差及公共缩放。

```bash
python3 experiments/dualcast_regions.py --output /tmp/dualcast-regions.json
python3 -m unittest discover -s experiments -p 'test_dualcast_regions.py' -v
```

实际损失为 7.433333328377778，常量残差损失为 3.999999997333333，5 项机制检查通过。[实验报告](../experiments/results/dualcast-regions.md) · [JSON](../experiments/results/dualcast-regions.json)

## 局限与思考

本地实验仅覆盖已对齐、二值化掩码上的损失语义。掩码缩放、时序对齐、条件槽位更新、完整视频训练及生成质量仍未验证。官方实现入口缺失使这些细节的复核受到限制。

后续可固定同一批预测与目标，只改变掩码面积及边界错误，记录每区域损失和梯度贡献，再评估局部监督是否过度依赖分割质量。完整实验还需保存身份独立划分、随机种子、预算以及视频质量和覆盖指标。
