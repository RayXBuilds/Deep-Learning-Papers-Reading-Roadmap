## 问题

给定训练样本，怎样训练一个把随机输入 z 映射成样本的 G？GAN 为生成器增加一个学习中的判别器 D。D 接收真实样本和生成样本，输出属于真实来源的概率，G 则通过 D 传回的梯度更新。核心任务由两个模型共同决定。原文 §3 给出目标和交替更新方法。[原文](https://arxiv.org/html/1406.2661v1)

读这一结构时，可以逐项记录随机输入、生成样本、真假标签和梯度路径。更新 D 时固定 G 的参数，更新 G 时固定 D 的参数并对 D 的输入求导。这能把“谁在训练”与“梯度通过谁”分开检查。

## 方法与关键推导

以下把原文 Eq. (1)–(6) 展开为可手算的有限状态例子。用 p 表示真实分布，q 表示生成分布，真样本标签为 1，假样本标签为 0。

```text
V(D,G) = E_p[log D(x)] + E_q[log(1-D(x))]
训练方向为 max_D V 与 min_G V
```

固定一个状态 x，记 p(x)=a、q(x)=b。对判别器输出 d 求导得到

```text
f(d)  = a log d + b log(1-d)
f'(d) = a/d - b/(1-d)
D*(x) = a/(a+b)
```

当 a、b 都为正时，二阶导数为负，驻点给出最大值。当仅一个概率为正时，最优点落在端点。a=b=0 的状态对目标贡献为零，可以任选输出。这个边界约定也是实现对数时需要单独处理的地方。

令 m=(p+q)/2，将最优判别器代回目标，利用 `log(p/(p+q)) = log(p/m)-log 2` 得到

```text
C(G) = V(D*,G) = -log 4 + KL(p||m) + KL(q||m)
     = -log 4 + 2 JS(p||q)
```

这里使用自然对数。最优判别器条件使分布匹配问题有清晰参照，p=q 时 C=-log 4，D*=1/2。实际训练还需要检查有限模型容量、判别器优化程度和交替步长，这些条件决定理论参照能否解释一次具体更新。

### 用 logit 看生成器的梯度

原文 §3 同时讨论 minimax 与非饱和目标。设某个生成样本的判别器 logit 为 s，D=σ(s)，两种待最小化的损失及其局部导数为

```text
L_MM = log(1-σ(s))       dL_MM/ds = -σ(s)
L_NS = -log σ(s)         dL_NS/ds = σ(s)-1
```

自己推导的检查是把导数进一步乘上 `ds/dx` 和 `dx/dθ_G`。当 s 很负时，第一项局部梯度接近零，第二项接近 -1。若后面的 Jacobian 很小，参数梯度仍会受到限制。因此实验分别报告 logit 导数和它能支持的结论范围。

再做一个可反驳的诊断。无论 p、q 相差多远，一个恒定输出 1/2 的 D 都会给出 V=-log 4。只有把判别器是否接近最优这一条件纳入检查，才能从该值讨论分布匹配。小实验使用 p=[0.75,0.25]、q=[0.25,0.75]，直接比较恒定判别器与 D*。

## 与其他论文的关系

- 与 VAE 构成目标对照。VAE 通过近似后验展开 ELBO，GAN 通过学习中的二分类器提供生成信号。比较时应分别列出似然评价、样本质量与覆盖指标。[VAE](vae.md)
- 与 DDPM 构成训练监督对照。GAN 的信号随 D 更新，DDPM 的噪声预测目标来自已知加噪过程。两者的采样预算和训练预算需要分别记录。[DDPM](ddpm.md)
- 与 CLIP 构成标签语义对照。CLIP 的标签指向批内图文配对，GAN 的真假标签指向样本来源。两者都使用分类形式的目标，比较时要把标签单位和优化参与者写清楚。[CLIP](clip.md)

这些关系用于组织阅读，具体机制分别由各精读中的原文位置支持。

## 可验证实验

运行以下命令可得到三种有限分布的 D*、JS 和 C，并比较 logit 为 -8、0、8 时的解析与有限差分导数。

```bash
python3 experiments/gan_objective.py --output /tmp/gan-objective.json
python3 -m unittest discover -s experiments -p 'test_gan_objective.py' -v
```

CPU 标准库，输入确定，seed=null。6 项机制检查通过。p=q 时 C=-1.386294361120，交换两状态概率后的 JS=0.130812035941，支持集分离时 JS=log 2。s=-8 时两种导数分别约为 -0.000335350130 和 -0.999664649870。等式容差 1e-12，有限差分步长 1e-5、容差 1e-8。[实验协议与结果](../experiments/results/gan-objective.md) · [原始记录](../experiments/results/gan-objective.json)

## 局限与思考

当前验证覆盖有限概率表与固定 logit，神经网络的交替训练、模式覆盖与图像质量尚未验证。非饱和目标的梯度分析适用于本节固定判别器的生成器更新，JS 等式适用于 minimax 目标代入最优判别器后的值。

下一步可在二维混合分布上固定容量和训练预算，分别改变 D/G 更新次数，记录每个模式的覆盖与多种子轨迹。需要预先定义覆盖标准，并同时观察判别器质量和生成分布，而后检验“判别器更准确是否总能帮助下一次生成器更新”这一问题。
