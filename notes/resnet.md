# ResNet：为什么加深网络之后反而更难训练？

[首页](../README.md) · [训练路线](../docs/roadmaps/training-and-vision.md) · [实验说明](../experiments/README.md)

- 原文：[Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)，He 等，2015 预印本 / CVPR 2016。
- 核对位置：第 3.1–3.3 节、图 1、图 2、第 4.1 节。
- 先修：卷积、链式法则、训练误差与测试误差。
- 状态：中文精读初版；配套机制实验；未复现 ImageNet 指标。

## 问题

论文关注的退化现象包括更深普通网络的训练误差变高。过拟合通常讨论训练表现与泛化的差距，因此不能仅用“层数多了更容易过拟合”解释这个现象。

## 方法与关键推导

把目标映射写作 H(x)，令分支学习 F(x)=H(x)−x，最终得到 y=x+F(x)。当需要近似恒等映射时，分支接近零即可。输入输出维度不同时，捷径需要投影等匹配方式。

对加法节点求导，得到 dy/dx=I+J_F(x)。它提供一条直接路径，但不保证所有深度、初始化和激活组合的梯度都稳定。原版残差块加法后还有 ReLU；本仓库的标量实验省略了它，不能直接等同原架构。

## 原论文证据

阅读图 1 中普通网络的训练误差，再看同深度普通/残差网络对照。关注控制条件，而不只是最终排行榜名次。第 4.1 节的 ImageNet 结果属于原论文实验，不是本仓库测量。

## 与其他论文的关系

VGG 强调加深卷积网络；ResNet 改变深层模块的参数化。Transformer 也使用残差连接，但其注意力、归一化顺序和训练条件不同。组件被复用，不意味着两个架构的完整训练规律相同。

## 可验证实验

```bash
python3 experiments/run.py --experiment residual
```

实验使用相同分支 F(x)=0.1 tanh(x)，比较反复应用 F 与 x+F 的输入导数。解析导数与中心差分相互核验，再观察深度增加时的变化。输出不是分类准确率，也没有训练权重。

## 局限与思考

实验刻意选择小分支，适合说明恒等路径；换成大分支可能放大梯度。修改深度和分支系数后重跑，分别记录数值与解释。思考：有捷径是否足以保证泛化？为什么维度变化时不能直接相加？
